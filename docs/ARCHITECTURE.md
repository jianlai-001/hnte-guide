# 工作台架构与能力边界

## 页面

| 页面 | 主要职责 |
| --- | --- |
| `index.html` | Three.js 三维地球、广东 21 市名录地图、最新政策和功能入口 |
| `workspace.html` | 工作区总览、结构分、必要材料覆盖、最近文件 |
| `audit.html` | 批量上传、文本抽取、自动分类、企业指标、结构审核和风险清单 |
| `organizer.html` | 按申报类别重组文件、建议命名、导出整理表 |
| `draft.html` | 基于结构化事实生成研发、产品、成果转化和创新能力说明草稿 |
| `guide.html` | 政策条件、评分、材料与风险参考 |

## 沉浸式交互层

除 `index.html` 指挥中心外，五个业务页面共享 `assets/experience.css` 和 `assets/vendor/experience.bundle.js`：

- `audit`：扫描环与数据隧道
- `organizer`：IP、RD、PS 节点网络
- `draft`：波动文档层
- `guide`：政策信息碑与轨道环
- `workspace`：文件立方体与资料星场

交互层负责背景 WebGL 场景、页面滚动进度、标题视差、卡片 3D 倾斜、元素进入视口、页面转场和自定义指针。
它不接管业务表单数据。触屏设备禁用卡片倾斜，减少动态偏好开启时停止自动动画。

## 数据流

```text
文件 / 文件夹 / ZIP
  → 浏览器本地文本抽取
  → 文件名与正文关键词分类
  → IndexedDB 保存文件与分析结果
  → 必要类别、解析状态、重复文件、敏感信息、企业指标审核
  → 人工确认分类和指标
  → 证据链整理
  → 结构化起草与人工复核
```

## 本地存储

- IndexedDB 数据库名：`hnte-workspace`
- `documents`：文件 Blob、抽取文本、分类、编号和敏感标记
- `settings`：企业指标
- `drafts`：保存的文书草稿

工作台没有后端服务，资料不会由本项目主动发送到外部。浏览器站点数据被清除、无痕会话关闭或浏览器存储空间不足时，数据可能丢失。

## 支持格式

| 格式 | 当前能力 |
| --- | --- |
| PDF | 解析可复制文字；扫描版 PDF 标记为待 OCR |
| DOCX | 解析正文文字；主要由图片组成的文档标记待处理 |
| XLSX / XLSM | 解析工作表文本数据 |
| TXT / MD / CSV / JSON / XML / HTML | 直接抽取文字 |
| ZIP | 在浏览器中展开，递归处理内部文件 |
| 图片、旧版 DOC/XLS | 当前不能自动抽取正文，提示人工处理 |

## 审核能力

当前版本可以检查：

- 11 个必要材料类别是否至少有一个可识别文件
- 文件是否解析成功或需要 OCR
- 完全相同的重复文件
- 分类置信度较低的文件
- 疑似身份证号、手机号、银行账号或薪酬/社保敏感主题
- 企业硬门槛指标是否达到全国性规则
- 资料中多个疑似统一社会信用代码可能冲突

当前版本不能可靠判断：

- 文档签名、公章和扫描件的真实真伪
- 专利、软著、合同、发票的官方状态和权利完整性
- 研发活动是否具有专家认可的技术先进性
- 合同发票是否形成完整闭环，或高新收入归集是否最终成立
- 申请书正文的论证质量是否足以通过专家评审
- 年度认定名录数等同于当前有效存量

三维指挥中心展示的是公开“认定/备案名录数量”，不是当前有效存量。广东省 2025 年名单不含深圳；深圳首批备案数量单独列示，避免重复计算。

因此，系统输出是“材料准备风险审核”，不是“全部资料一定符合要求”或“申报一定通过”的证明。

## 起草能力

起草页使用确定性模板，把企业填写的项目名称、技术、指标、知识产权、研发过程和成果组织成文书结构。它不会自动补充不存在的事实：

- 没有测试材料时不生成具体性能指标
- 没有立项、过程或结题证据时不宣称研发已完成
- 没有合同和发票时不编写收入贡献
- 没有成果转化记录时不增加转化数量

如需进一步实现中文长文生成、跨文件冲突解释或基于证据的自动改写，应增加受控的 OCR 和模型服务，同时明确数据出域、脱敏、审计日志和人工确认机制。

## 后续扩展接口

建议按以下顺序增强：

1. 增加本地 OCR，处理扫描 PDF 和图片。
2. 增加财务表格结构识别，自动比对研发费用和收入汇总。
3. 增加 PDF 公章、签章页和二维码报告的格式检查。
4. 增加证据链编号校验，即 IP → RD → PS → 合同/发票的交叉引用。
5. 接入企业自主选择的模型服务，生成候选表述，但每条结论必须回链到原始证据。
