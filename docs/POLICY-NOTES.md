## 为什么没有采用“2026 评分大改”说法

检索中可见部分自媒体或非官方解读声称 2026 年会改变知识产权权重、增加 I 类知识产权硬性数量或实行新的评分表，但这些内容没有在当前可核验的主管部门正式文件、当年度省级或市级申报通知中找到一致依据。

因此本项目：

- 不把未确认的变化写入硬规则或评分计算；
- 不在页面上承诺某一版规则将长期有效；
- 保留政策来源和核验日期，便于后续增补；
- 对地方年度要求使用“以当地通知为准”的明确提示。

如果未来出现新的全国性正式文件，应通过 Issue 或 Pull Request 提交来源，并同时更新：

1. `assets/data.js` 中的条件、流程、评分和来源；
2. `assets/engine.js` 中受影响的计算逻辑；
3. `tests/engine.test.js` 中对应测试；
4. `docs/CHECKLIST.md` 和页面上的政策核验日期；
5. `CHANGELOG.md` 中的变更记录。

## 可接受的政策来源

优先级从高到低：

1. 国务院、科技部、工业和信息化部、财政部、国家税务总局等主管部门正式文件；
2. 省级、计划单列市认定机构或主管部门的当年度正式通知；
3. 官方认定系统发布的填报说明和模板；
4. 地方税务、财政、人社等部门发布的配套文件。

仅提供以下内容的变更建议通常不会直接合并：

- 商业培训文章；
- 自媒体政策解读；
- 未注明发布日期和适用地区的截图；
- 以“内部消息”为依据的审核口径；
- 无法核验原文的申报通过率或评分变化。

## 贡献政策更新时请提供

- 文件全名和文号
- 发布机关
- 发布日期与生效日期
- 适用地区和年度
- 官方原文链接
- 受影响的具体项目或计算
- 旧口径与新口径的差异

## 责任边界

本项目是申报准备工具，不是官方政策数据库，也不对具体申报结果负责。任何提交都应由使用者结合企业实际情况和当地主管部门要求复核。
