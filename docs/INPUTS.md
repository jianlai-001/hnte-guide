# 申报数据输入模板

本模板用于把通用开源工具进一步定制为企业申报工作台。请先提供脱敏信息，不要在公开 Issue 或仓库中提交真实敏感材料。

## 直接导入整套资料

工作台支持三种导入方式：

1. 在“资料审核”页选择多个文件。
2. 选择包含完整申报材料的整个文件夹。
3. 把资料目录压缩为 ZIP 后一次导入。

更适合自动整理的目录示例：

```text
企业申报资料/
├─ 01_主体资质/
│  └─ 营业执照.pdf
├─ 02_知识产权/
│  ├─ 发明专利/
│  └─ 软件著作权/
├─ 03_研发项目/
│  ├─ RD01/
│  │  ├─ 立项报告.pdf
│  │  ├─ 过程记录.docx
│  │  └─ 结题验收.pdf
│  └─ RD02/
├─ 04_产品与服务/
├─ 05_成果转化/
├─ 06_人员/
├─ 07_财务与专项报告/
├─ 08_纳税申报/
└─ 09_合同发票与收入/
```

系统会对文件正文抽取文字并自动分类。文件名清晰、正文可复制、避免重复副本，可以明显提高自动审核准确度。

## 第一批：确定政策和申报范围

必填：

1. 企业所在省、市、区/园区
2. 计划申报年度，例如 2027 年
3. 本次是首次认定还是重新认定
4. 企业当前高新技术企业证书有效期（如适用）
5. 当地主管部门已经发布的正式通知链接（如已有）
6. 当前最需要解决的问题：资格判断、材料清单、评分提升、时间规划或系统填报

如果没有当地通知，请至少确认所在省市，项目才能标注地方待核验项。

## 第二批：硬门槛初筛

以下数据应尽量使用经财务、人事复核后的口径：

- 企业注册成立日期
- 最近一年销售收入
- 近三个会计年度销售收入合计
- 近三个会计年度研发费用合计
- 其中境内研发费用合计
- 最近一年高新技术产品（服务）收入
- 最近一年企业总收入
- 当年职工总数和科技人员数的全年月平均数
- 是否存在申请前一年重大安全、质量、环境事故或严重违法行为

可使用“金额区间”而不是精确值进行第一轮判断，但正式申报必须以审计和申报表数据为准。

## 第三批：技术与知识产权概览

每项知识产权可只提供：

- 类型：发明专利、实用新型、外观设计、软件著作权、集成电路布图设计等
- 是否有权：是 / 否 / 待核实
- 取得方式：自主研发、受让、受赠、并购
- 是否与主要产品相关
- 是否曾用于本企业或其他企业的高企认定（II 类尤其需要确认）
- 对应产品或研发项目编号

请勿发送证书上不必要的个人身份证号、发明人住址等信息。

## 第四批：产品、研发和成果转化

- 主要产品（服务）名称及一句话技术说明
- 拟对应的《国家重点支持的高新技术领域》三级方向
- 每个主要产品的关键技术或技术指标
- 代表性研发项目名称、周期、目标和成果
- 近三年可证明的成果转化数量
- 产品收入的主要合同/交付形态
- 产品认证、测试报告、生产资质的大类（如有）

可以使用 `PS01`、`RD01`、`IP01` 这类内部编号代替真实名称。

## 第五批：管理、人员和财务现状

- 是否有研发项目管理制度
- 是否建立研发费用辅助账
- 是否有内部研发机构
- 是否有产学研合作
- 是否有成果转化和人才激励制度
- 审计报告、专项报告、纳税申报表之间是否存在已知差异
- 当前材料准备的完成度或最担心的部分

## 适合公开仓库的示例

```text
地区：华东某市
申报类型：首次认定
最近一年销售收入：8,000 万元
近三年研发费用：900 万元，其中境内 810 万元
职工总数/科技人员：100 / 20 人
高新收入/总收入：5,200 / 8,000 万元
I 类知识产权：1 项发明专利，自主研发，对应 PS01
II 类知识产权：4 项软著，2 项曾用于历史申报
主要问题：RD 项目与收入证据链不完整
```

## 不应发到公开渠道的材料

- 身份证号、手机号、家庭住址
- 完整社保或工资名单
- 未脱密客户合同、订单、发票、银行流水
- 财务报表原始底稿和税号等敏感字段
- 申报系统账号、密码、验证码或访问令牌
- 未公开技术方案、源代码和商业秘密

如需处理真实明细，应在企业授权的受控环境中进行，并遵守组织的数据安全和保密制度。
