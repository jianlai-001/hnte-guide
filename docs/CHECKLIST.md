# 高新技术企业认定申报材料清单

> 政策基准：《高新技术企业认定管理办法》（国科发火〔2016〕32号）与《高新技术企业认定管理工作指引》（国科发火〔2016〕195号）。核验日期：2026-10-23。申报前必须以企业所在地当年度通知为准。

## A. 先完成硬门槛自查

- [ ] 申请时注册成立满 365 个日历天
- [ ] 主要产品（服务）拥有核心知识产权所有权
- [ ] 核心 IP 对主要产品发挥技术支撑作用
- [ ] 核心技术属于《国家重点支持的高新技术领域》
- [ ] 科技人员占当年职工总数不低于 10%，并按全年月平均数计算
- [ ] 近三年研发费用占同期销售收入达到 5% / 4% / 3% 对应档位
- [ ] 境内研发费用占全部研发费用不低于 60%
- [ ] 近一年高新技术产品（服务）收入占同期总收入不低于 60%
- [ ] 创新能力综合得分可达到 70 分以上（不含 70 分）
- [ ] 申请前一年无重大安全、重大质量事故或严重环境违法行为

## B. 主体和申报文件

- [ ] 高新技术企业认定申请书
- [ ] 营业执照等依法成立证明
- [ ] 企业承诺书及当地通知要求的声明
- [ ] 官方系统注册号和企业基本信息
- [ ] 法定代表人、联系人和经办人信息
- [ ] 地方系统与全国系统主体信息一致

## C. 知识产权

- [ ] 知识产权证书，或授权通知书与缴费收据
- [ ] 当前法律状态和权利人查询结果
- [ ] 受让、受赠、并购取得的权属变更证明
- [ ] 多权属人时仅由一个权属人使用的承诺或多方协议
- [ ] 知识产权与主要产品关键技术的对应说明
- [ ] 知识产权与研发项目、产品及收入的对应表
- [ ] II 类知识产权历史使用情况核查
- [ ] 参与标准制定的认证认可证明（加分项）

## D. 研发活动

- [ ] 近三年研发活动汇总表
- [ ] 每个研发项目的立项决议或审批文件
- [ ] 研发计划、目标、技术路线和预算
- [ ] 项目参与人员和工时/分工记录
- [ ] 阶段成果、测试记录和过程材料
- [ ] 验收或结题报告
- [ ] 研发项目与 IP、产品、收入之间的映射
- [ ] 研发活动不属于常规升级或科研成果直接应用的说明

## E. 高新技术产品与服务

- [ ] 主要产品（服务）清单
- [ ] 关键技术和技术指标说明
- [ ] 产品与同类产品竞争优势说明
- [ ] 生产批文、认证认可或资质证书（如适用）
- [ ] 产品质量检验或第三方测试报告
- [ ] 代表性合同、发票、验收和交付材料
- [ ] 合同与发票收入和专项报告收入勾稽表
- [ ] 主要产品（服务）收入合计占高新收入超过 50% 的核查

## F. 科技成果转化

- [ ] 近三年成果转化逐项清单
- [ ] 成果来源及权属证明
- [ ] 转化方式与实施载体
- [ ] 形成的产品、服务、工艺、样机或新材料证明
- [ ] 应用成效、客户验证或收入贡献
- [ ] 同一成果避免重复计数
- [ ] 年平均转化项数与评分档位复核

## G. 研发组织管理

- [ ] 研发组织管理制度
- [ ] 研发投入核算体系和研发费用辅助账
- [ ] 内部研发机构设置和科研条件
- [ ] 产学研合作协议及实际成果
- [ ] 成果转化组织实施、激励和开放创新平台制度
- [ ] 科技人员培养、培训、引进和绩效奖励制度
- [ ] 制度公布、执行和过程记录

## H. 人员

- [ ] 当年职工总数和科技人员数计算表
- [ ] 全年月平均数计算明细
- [ ] 科技人员名册、岗位、学历和在职时间
- [ ] 劳动合同、社保或有效用工证明
- [ ] 兼职、临时人员累计工作 183 天以上记录
- [ ] 科技人员与研发项目、工时分配的对应关系
- [ ] 外籍、留学归国等特殊人员材料（如适用）

## I. 财务与中介报告

- [ ] 近三个会计年度财务会计报告
- [ ] 会计报表、附注和财务情况说明书
- [ ] 近三个会计年度企业所得税年度申报表主表及附表
- [ ] 近三年研发费用专项审计或鉴证报告
- [ ] 近一年高新技术产品收入专项审计或鉴证报告
- [ ] 中介机构资质、人员和不良记录符合当地要求
- [ ] 报告签字、盖章、编码和二维码可查验
- [ ] 销售收入、总收入、净资产、研发费用跨表勾稽
- [ ] 所有差异有合法、可解释的调整依据

## J. 提交前最后检查

- [ ] 逐条阅读企业所在地当年度正式通知
- [ ] 使用通知指定的申报系统和批次
- [ ] 系统内数据与附件、审计报告和纳税申报表一致
- [ ] 扫描件清晰、方向正确、文件命名统一
- [ ] 签字、公章和骑缝章符合要求
- [ ] 提交后保留完整电子包
- [ ] 打印并装订完整纸质材料存档
- [ ] 技术、财务和人事联系人保持可响应
- [ ] 未把真实敏感资料上传到公开代码仓库

## K. 认定后的持续义务

- [ ] 关注公示、备案和证书信息
- [ ] 每年 5 月底前填报年度发展情况报表
- [ ] 企业更名或发生重大变化后三个月内报告
- [ ] 持续满足人员、研发费用和高新收入等条件
- [ ] 到期前提前启动重新认定

## 使用提示

清单是准备工作骨架，不是官方表格替代品。不同地区可能要求额外附件、不同模板、不同报告查验方式或更早的内部预审日期，应以当地主管部门最新通知为准。
